# Priyanka - Test Engineer Portfolio

## Publish the portfolio
1. Create a free GitHub account (if you don't already have one).
2. Create a new public repository named `priyanka-test-engineer-portfolio`.
3. Upload `index.html`.
4. Open Settings → Pages → Deploy from branch → `main` → `/root`.
5. GitHub will generate your public portfolio URL.

Then paste that URL into your job profile's **Portfolio** field.
